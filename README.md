# Python Learning Journey

A personal collection of Python exercises and mini-projects, organized by topic as I build up from fundamentals toward AI/ML concepts.

## Structure

### `01_basics/`
Core language fundamentals and small algorithmic exercises.
| File | What it does |
|---|---|
| `evenorodd.py` | Checks whether a number is even or odd |
| `temperature.py` | Converts between Celsius and Fahrenheit |
| `school_grade.py` | Classifies a numeric score into a letter grade, with input validation |
| `variables_dynamic_typing_safe_calculator.py` | A calculator demonstrating Python's dynamic typing with safe numeric coercion |
| `vectorized_filtering.py` | List-comprehension based filtering/normalization of numeric readings |
| `prime_sieve_search.py` | Finds primes up to a limit using the Sieve of Eratosthenes |
| `word_frequency.py` / `npl_frequency_counter.py` | Word/term frequency counters over text |
| `simple_operations.py` | Basic data exploration using pandas/matplotlib on the Anscombe dataset |

### `02_mini_projects/`
Small, self-contained applications.
| File | What it does |
|---|---|
| `calendar_app.py` | A calendar utility built with Python's `calendar` module |
| `my_qrcode.py` | Generates a QR code from a URL |
| `text_to_speech_generator.py` | Converts text to speech using `gTTS` |
| `todo_list.py` | A simple command-line to-do list manager |

### `03_aiml_foundations/`
Early exercises exploring AI/ML concepts.
| File | What it does |
|---|---|
| `perception.py` | Basic perceptron-style logic |
| `neural_navigator.py` | Neural-network-inspired navigation/exploration exercise |
| `simulation.py` | A simulation exercise tying the above together |

## Running the scripts

Most scripts run standalone:

```bash
python3 01_basics/evenorodd.py
```

Some mini-projects need extra packages:

```bash
pip install qrcode gtts pandas matplotlib seaborn
```
